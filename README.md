# Indian Motorcycle Market & Sales Analysis

## Project Overview
This project uses Power BI to analyze the Indian motorcycle market using the `bike_sales_india` dataset. The dashboard focuses on motorcycle registrations, pricing, mileage, and brand-level comparisons to help users understand market patterns and motorcycle characteristics.

## Objectives
- Analyze motorcycle registrations across different brands.
- Compare brands such as Honda, Yamaha, Hero, Bajaj, KTM, and others.
- Calculate total motorcycle prices and average prices.
- Analyze average mileage (km/l).
- Explore motorcycle data by state, fuel type, and other available attributes.
- Create interactive brand buttons using Power BI bookmarks to display brand-specific information.

## Tools Used
- **Power BI** — Dashboard development and data visualization
- **DAX** — Calculated measures and brand-level analysis

## Key Dashboard Features
- Total motorcycle registrations
- Total motorcycle price
- Average motorcycle price
- Average mileage (km/l)
- Brand-specific analysis for Honda and other manufacturers
- Interactive buttons and bookmarks for navigating between brand views
- Charts for exploring registration patterns and fuel types

## Business Questions
1. Which motorcycle brands have the highest number of registrations?
2. How do motorcycle prices differ across brands?
3. Which brands offer higher average mileage?
4. How do registrations vary by state and fuel type?
5. How can interactive dashboards help users compare motorcycle brands?

## Key Learning Outcomes
- Creating interactive Power BI dashboards.
- Writing DAX measures using `CALCULATE`, `COUNTROWS`, `SUM`, and `AVERAGE`.
- Using bookmarks and buttons to navigate between brand-specific views.
- Presenting data through clear, interactive visualizations.

## Conclusion
This project demonstrates my practical Power BI skills in data analysis, DAX, and dashboard development. It helped me practice transforming motorcycle data into interactive visual insights for comparing brands, registrations, prices, and mileage.
